1. Pendahuluan

Butik Busana Fashion adalah aplikasi e-commerce berbasis Progressive Web App (PWA) untuk toko busana wanita muslim (gamis, tunik, dress, hijab, kebaya, dan aksesoris). Aplikasi mendukung katalog, keranjang, checkout, pembayaran Midtrans Snap (VA, QRIS, e-wallet), serta notifikasi push untuk status pesanan dan pengingat deadline pembayaran.

1.1 Tujuan

  • Menyediakan belanja online yang dapat diinstal sebagai PWA.
  • Memfasilitasi pembayaran otomatis via Midtrans.
  • Mengirim push terkait pembayaran, pembatalan, dan deadline.
  • Membatalkan pesanan otomatis jika melewati batas waktu.
  • Memberikan panel admin untuk operasional toko.

1.2 Ruang Lingkup

Modul pelanggan (katalog, keranjang, checkout, transaksi, push) dan modul admin (produk, koleksi, pesanan, rekening, slider/marquee). Integrasi: Midtrans, Cloudinary, Web Push (VAPID), cron eksternal.

2. Teknologi yang Digunakan

  • Next.js 16 (App Router), React 19, TypeScript
  • Ant Design, Tailwind CSS
  • NextAuth.js (Credentials + JWT)
  • MongoDB + Prisma ORM
  • TanStack React Query, Zustand
  • Midtrans Snap, Cloudinary, web-push, Workbox PWA

URL lokal: http://localhost:3000

4. Struktur Database

Database MongoDB melalui Prisma. Model utama: Role, User, Collection, Product, Cart, Order, PaymentEvidence, RekeningBank, PushSubscription, plus konfigurasi situs (slider/marquee).

  • User 1—N Order, Cart, PushSubscription
  • Collection 1—N Product
  • Order menyimpan status, paymentStatus, deadline reminder fields
  • PushSubscription: endpoint + keys; satu aktif per user

5. Fitur per Modul

5.1 Pelanggan

  • Auth: register, login, logout
  • Katalog & detail produk, filter koleksi
  • Keranjang (guest localStorage / user server)
  • Checkout → buat order → Midtrans Snap
  • Transaksi: bayar ulang, batalkan manual
  • Push dari navbar

5.2 Admin

  • Dashboard /admin
  • CRUD produk & koleksi
  • Kelola pesanan, rekening bank, slider, users

5.3 Pembayaran Midtrans

  • createOrder menyimpan pesanan NOT_PAID
  • orderTokenizer + Snap dengan orderId
  • Webhook /api/midtrans-notification → PAID + push

5.4 Push & Cron

  • POST /api/push/subscribe
  • GET /api/cron/payment-deadline-reminder
  • GET /api/cron/cancel-expired-orders
  • Header: Authorization: Bearer <CRON_SECRET>

6. Alur Login dan Hak Akses

  • Login di /login via NextAuth + bcrypt
  • Guest: katalog & cart lokal
  • Customer: checkout, bayar, batalkan, push
  • Admin: panel /admin

8. Alur Penggunaan

  1. Jelajahi katalog → tambah ke keranjang.
  2. Login/register → isi data checkout.
  3. Konfirmasi → order tersimpan → Midtrans Snap terbuka.
  4. Aktifkan notifikasi di navbar.
  5. Admin kelola produk & pesanan di /admin.

9. Instalasi dan Menjalankan

  1. npm install
  2. npm run generate-vapid → isi VAPID di .env
  3. Set DATABASE_URL, Midtrans, NextAuth, Cloudinary, CRON_SECRET
  4. npm run db:push && npm run db:seed
  5. npm run dev → http://localhost:3000

10. Catatan Keamanan dan Pengembangan

  • Password bcrypt; sesi JWT NextAuth
  • Role-based akses admin
  • Webhook Midtrans diverifikasi sebelum update
  • Cron dilindungi Cron Secret
  • Subscribe push menghapus endpoint lama per user
