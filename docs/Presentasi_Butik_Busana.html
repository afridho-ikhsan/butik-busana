Presentasi Aplikasi

Butik Busana Fashion

E-commerce Progressive Web App untuk busana wanita muslim — Midtrans, push notification, dan manajemen pesanan otomatis.

Pendahuluan

Apa itu Butik Busana?

Platform belanja online yang bisa diinstal sebagai PWA, fokus pada pengalaman checkout dan notifikasi status pembayaran.

  • Katalog produk, keranjang, dan checkout dengan kurir
  • Pembayaran Midtrans Snap (VA, QRIS, e-wallet)
  • Push notification deadline & status pesanan
  • Panel admin untuk produk, koleksi, dan pesanan
Teknologi

Stack yang Digunakan

Frontend

  • Next.js 16 · React 19 · TypeScript
  • Ant Design · Tailwind CSS
  • TanStack Query · Zustand

Backend & Integrasi

  • MongoDB · Prisma · NextAuth
  • Midtrans Snap · Cloudinary
  • Web Push (VAPID) · Cron Secret

Admin

Produk, koleksi, pesanan, rekening, slider

Cron

Alur Inti

Proses Pembayaran

  • Validasi form → dialog konfirmasi data
  • Buat pesanan ke database (belum bayar)
  • Buka Midtrans Snap dengan orderId
  • Webhook update PAID + kirim push
  • Tutup Snap → tetap ke daftar transaksi
Alur Inti

Push & Cron

Aktifkan Push

  • Izin Notification browser
  • Service Worker + VAPID
  • Simpan endpoint (1 aktif / user)

Sistem Cron

  • Reminder 30 / 15 / 5 menit
  • Batalkan pesanan kedaluwarsa
  • Proteksi Cron Secret (Bearer)
Penutup

Kesimpulan

  • E-commerce PWA siap untuk operasional toko busana
  • Pembayaran Midtrans terintegrasi webhook & push
  • Deadline pembayaran dikelola otomatis via cron
  • Admin lengkap untuk katalog dan pesanan
